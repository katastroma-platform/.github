# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Email:** [nathan@sonicoriginal.software](mailto:nathan@sonicoriginal.software)

Include:

- A description of the vulnerability
- Steps to reproduce
- Affected component(s) and version(s)
- Any potential impact you have identified

## Response

You can expect an initial acknowledgment within 72 hours. We will work with you
to understand the issue and coordinate a fix before any public disclosure.

## Scope

This policy applies to all repositories in the katastroma organization.
